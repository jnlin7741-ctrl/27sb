绘卷水浒 · 音乐文件放这里
================================

现用全站默认曲（首页与所有人物页共用）：
  堂前燕 改编 · 笛子版「牵丝戏」（纯音乐）
  → 文件名请放成 audio/bgm.mp3

命名规则（与石碣座次同号，见 images/chNNN.jpg）：

  全站默认曲    audio/bgm.mp3        ← 每位人物没单独指定曲目时，用它
  个人专属曲    audio/001.mp3 … 108.mp3

在 stories.js 里给某个人指定专属曲：

  window.STORIES={ '013':{ music:'audio/013.mp3' } };

支持 mp3 / m4a / ogg / wav（浏览器原生能否解码取决于格式，
mp3 最稳）。

播放行为：
  · 打开首页或任何人物页都会**自动试播**；
  · 浏览器禁止有声自动播放时，页面右下角会出现「启卷」浮标，
    读者第一次点按屏幕的任何地方（或按任意键）即自动起播；
  · 点浮标可「止乐 / 启卷」；关掉后，再翻看其他页面都保持安静
    （不会因为随便点一下又自己响起来）；
  · 从甲翻到乙（同一曲目）会接着上一页的播放位置继续，不从头来过；
  · 若 audio/bgm.mp3 不存在，页面不会出现任何音乐 UI。
